# GitHub Catppuccin Mocha Custom

A polished UserCSS style that brings the complete Catppuccin Mocha palette to GitHub and Gist. It completely restyles GitHub using native CSS color variables and adds dynamic theme options for a cleaner developer experience.

## Features

- Full dark mode theme replacement for GitHub and Gist using Catppuccin Mocha colors.
- Interactive UserCSS accent picker to customize UI highlights in real time.
- Enhanced contribution graph with glowing intensity levels and smooth hover zoom animations.
- Modernized UI elements including rounded cards, sleek input fields, custom scrollbars, and dynamic background gradients.
- Comprehensive syntax highlighting for Markdown previews, code blocks, issue badges, and pull request statuses.

## Installation

1. Install a browser extension that supports UserCSS, such as Stylus.
2. Enable "Write styles in UserCSS format" in your extension settings.
3. Create a new style, paste the code, and click Save.
